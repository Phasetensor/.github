# Security policy

Do not disclose exploitable vulnerabilities in public issues. Use GitHub private vulnerability reporting where enabled, or contact a repository maintainer privately. Do not include secrets or sensitive personal data.

Include affected versions, impact, minimal reproduction steps, and relevant environment information. Coordinate disclosure with maintainers. No response deadline or supported-version guarantee is implied unless documented by the individual project.

Ordinary numerical accuracy issues can be reported publicly unless they create a security risk.
