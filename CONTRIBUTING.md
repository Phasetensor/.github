# Contributing to PhaseTensor

Discuss substantial changes in an issue before implementation. Identify the research problem, existing approaches, assumptions, and measurable acceptance criteria.

Use a focused branch and pull request. Include tests, type annotations for public APIs, documentation, and a reproducible example. Numerical changes must explain tolerances, reference solutions, random seeds where applicable, and failure cases. Do not include credentials, private datasets, or proprietary material.

Run the repository's documented checks locally. Maintainers review scientific validity, software quality, and compatibility before merging. Contributions are subject to the license of the target repository; where no license is present, discuss licensing before contributing.
